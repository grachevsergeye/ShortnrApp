# React + Vite Url shortener!✌️
This is a full-stack URL shortener using React JS, Tailwind CSS, Supabase, and ShadCN UI.
-------------
For the project to start just download zip file, open it in your text redactor and install all the dependencies.

You also need to create a supabese acc. for the project to work and create a .env file with all the keys to connect your DB.
